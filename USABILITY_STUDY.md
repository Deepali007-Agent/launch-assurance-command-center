# Formative usability study protocol

Recruit five retail operations participants. Use equivalent launches and alternate which interface is used first: spreadsheet-first for some, prototype-first for others. Record prior retail/domain experience. Explain that this is a formative study, not statistically conclusive research.

Tasks: identify blocked SKUs; choose a permitted launch subset; assign the next team; compare logistics alternatives; correct a source record; revalidate; explain whether the previous decision remains current.

Record task start/end, missed critical blockers, invalid releases, correct ownership, completion without help and self-rated decision clarity (1–5). Keep operator-reported confidence separate from model evidence quality. Capture reasons for errors and observed confusion. Do not claim time savings until both conditions have been observed.

Workflow measures: correct team assignments / reviewed blockers; assigned due dates / assigned blockers; acknowledged handoffs / eligible handoffs; elapsed correction-to-revalidation time; repeat correction count; correct invalidations / tested upstream revisions. Define denominators and missing observations before collecting results.

Status: protocol prepared; no participant study has been conducted and no manual-effort improvement is claimed. Review the benchmark labels independently before quoting synthetic detection performance externally.
